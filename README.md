A linguagem de programação Python utiliza Objeto, Método e Módulo para estruturar sua sintaxe e ordenar as instruções.

- Objeto: pode ser usado para armazenar letras, palavras, frases, listas e valores que o desenvolvedor queira referenciar no código. 
- Método: comando que contém um conjunto de atividades pré-programadas. Um método **utiliza** um objeto como parâmetro/atributo.
- Módulo: são algumas ruínas que já estão organizadas na linguagem. Eles podem ser importados por outro programa para que o desenvolvedor utilize suas funcionalidades, como o módulo *math* que contém operações mais complexas como raiz quadrada, fatorial, dentre outras.

## Loops
Essas estruturas, incluindo listas, tuplas, dicionários e conjuntos, têm características únicas e são usadas para propósitos diferentes. Aqui está uma breve visão geral de como os loops são comumente usados com essas estruturas de dados:

- Strings: em Python, strings são iteráveis. Cada iteração através de uma string acessar um caractere por vez.
- Listas: são coleções ordenadas e mutáveis de itens. Elas podem conter elementos de diferentes tipos, incluindo outras listas. 
- Tuplas: são semelhantes às listas, porém são imutáveis. São frequentemente usadas para armazenar uma coleção de dados heterogêneos. 
- Dicionários: são coleções não ordenadas de pares chave-valor.

Existem diversas outras estruturas de dados, usadas em contextos e necessidades diferentes. 

## for loop em Python

Representa uma das formas mais comuns de estrutura de repetição, permitindo iterar sobre uma sequência de elementos e executar um bloco de código múltiplas vezes. 

## Estruturas de repetição 

**[Estruturas de repetição](https://hub.asimov.academy/blog/estruturas-de-repeticao-o-que-sao/)**, como o for loop, são fundamentais na programação, pois permitem que um bloco de código seja executado várias vezes, economizando tempo e esforço.

Em Python, temos duas principais estruturas de repetição: o **for loop** e **while loop**. O for loop é usado quando sabemos de antemão quantas vezes queremos repetir um bloco de código, enquanto o while loop é usado quando a repetição depende de uma condição que pode mudar durante a execução do programa.
